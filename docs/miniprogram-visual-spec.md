# 小程序视觉规范

> 来源：已确认的 6 张参考图（首页 2 张、店铺页 1 张、个人中心 1 张、商品详情 2 张）
> 与 `DESIGN_SPEC.md` 的苹果风 token。
> 本规范只适用于小程序与 H5 商城端；管理后台仍按 `DESIGN_SPEC.md` 执行。

## 1. 与后台规范的差异

| # | 差异 | 说明 |
|---|---|---|
| 1 | 允许受控渐变 | 后台规范禁止渐变；小程序允许三类渐变：会员卡、主 CTA 按钮、会员等级标签 |
| 2 | 金额带 `¥` 符号 | 后台规范「只显示数字」；小程序按参考图显示 `¥358.00` 形态 |
| 3 | 整数金额省略小数 | 建议 `¥358`，非整数 `¥358.50`；后台固定两位小数 |
| 4 | 固定语义色 | 价格红、自营蓝、进行中青不随平台主题变化；主色仍由平台配置驱动 |
| 5 | 商品图比例 | 建议统一 1:1，不做高度不等的真瀑布流 |

## 2. 设计 token

### 2.1 颜色

| 用途 | 取值 | 备注 |
|---|---|---|
| 主色 | 平台配置 `primaryColor`，默认 `#0071e3` | 选中态、链接、强调文字 |
| tabBar 选中色 | 平台配置 `tabColor`，默认 `#0071e3` | 自定义 tabBar |
| 页面背景 | 平台配置 `backgroundColor`，默认 `#f5f6f8` | |
| 卡片 | `#ffffff` | |
| 主文字 | `#1a1a1a` | |
| 次文字 | `#8a8a8f` | |
| 三级文字 / 占位 | `#b8b8be` | |
| 分割线 | `#efeff2` | |
| 价格红 | `#e93b3b` | 固定语义色 |
| 自营蓝 | `#2f6bff` | 固定语义色 |
| 进行中 / 成功 | `#00c2a8` | 固定语义色 |
| 警告 | `#ff9f0a` | |
| 危险 | `#ff3b30` | |
| 遮罩 | `rgba(0,0,0,0.4)` | |

### 2.2 受控渐变

| 用途 | 渐变 |
|---|---|
| 会员卡 | `linear-gradient(120deg, #7fd8c9 0%, #6fa8f5 55%, #a87bf0 100%)` |
| 会员等级标签 | `linear-gradient(90deg, #34c7e0 0%, #7b61ff 100%)` |
| 加入购物车 | `linear-gradient(90deg, #ffc53d 0%, #ff9f0a 100%)` |
| 立即购买 | `linear-gradient(90deg, #ff9f0a 0%, #ff3b30 100%)` |

### 2.3 间距（rpx，750 设计宽度）

只允许：`8 / 16 / 24 / 32 / 40 / 48 / 64`。

| 用途 | 值 |
|---|---|
| 页面左右边距 | 24 |
| 卡片内边距 | 24 |
| 卡片之间 | 20 |
| 区块之间 | 24 |

### 2.4 圆角

| 用途 | 值 |
|---|---|
| 小标签 | 8 |
| 输入框 / 小卡 | 12 |
| 图片 | 16 |
| 卡片 | 20 |
| 大卡 / 底部弹层 | 24 |
| 胶囊（按钮 / 搜索 / chips） | 999 |

### 2.5 字号（rpx）

| 层级 | 字号 | 字重 |
|---|---|---|
| 导航标题 | 34 | 500 |
| 区块标题 | 34 | 600 |
| 卡片标题 | 30 | 600 |
| 商品名 / 正文 | 28 | 400 |
| 副文本 | 24 | 400 |
| 说明文字 | 22 | 400 |
| 价格整数 | 44 | 600 |
| 价格小数 / `¥` | 26 / 24 | 600 / 500 |
| 统计数字 | 48 | 600 |
| 按钮文字 | 30 | 500 |

### 2.6 阴影

| 用途 | 值 |
|---|---|
| 卡片 | `0 4rpx 20rpx rgba(0,0,0,0.04)` |
| 悬浮 / 吸底 | `0 8rpx 32rpx rgba(0,0,0,0.08)` |
| 弹层 | `0 16rpx 48rpx rgba(0,0,0,0.12)` |

### 2.7 动效

`150ms`（hover / 按下）、`250ms`（展开收起 / 弹层）、`400ms`（页面转场），
统一 `cubic-bezier(0.4, 0, 0.2, 1)`，尊重 `prefers-reduced-motion`。

## 3. 基础组件

| 组件 | 规范 |
|---|---|
| 导航栏 | 高 88rpx + 状态栏；白底；标题居中 34rpx；返回热区 ≥ 88rpx |
| 搜索胶囊 | 高 72rpx，胶囊圆角；白底或 `#f2f3f5`；放大镜 32rpx；占位 #8a8a8f |
| 区块头 | 左侧标题 34rpx/600；右侧「查看更多 ›」24rpx 次文字 |
| 商品卡（网格） | 图 1:1 圆角 16；名称 28rpx 两行截断；价格行 + 自营标签 |
| 商品卡（单列） | 左图 200rpx 方形；右侧名称、规格、价格 |
| 价格 | `¥` 24rpx + 整数 44rpx/600 + 小数 26rpx；颜色 #e93b3b；整数省略小数 |
| 自营标签 | 20rpx；#2f6bff 描边或浅底；圆角 8 |
| 活动卡 | 图 16:9 圆角 16；标题 30/600；时间 22 次文字；状态「进行中」价格红；进度条青色 6rpx |
| 会员卡 | 渐变底、圆角 24、内边距 32；白字；等级胶囊；三项统计 |
| 统计行 | 三列居中；数字 48/600；标签 24 次文字 |
| 服务宫格 | 5 列；图标 56-64rpx；标签 24rpx；行间距 32 |
| 自定义 tabBar | 高 100rpx + 安全区；图标 48rpx；标签 22rpx；选中 tabColor，未选中 #9a9aa0；顶部 1rpx 分割线 |
| 图标规范 | 统一使用 `uni-icons` 字体图标；导航、搜索、购物车、收藏、服务入口、空状态不得使用文字字符或临时 SVG；交互图标热区不小于 88rpx |
| 排序 / 筛选栏 | 高 80rpx；文字 28rpx；选中主色 600；价格带升降箭头 20rpx |
| chips | 28rpx；内边距 12/24；胶囊；未选 `#f2f3f5`，选中白底 + 主色文字；Tab 型选中用主色下划线 |
| 按钮 | 主按钮胶囊高 88rpx；文字 30/500；禁用态透明度 0.4 |
| 详情吸底栏 | 白底 + 上阴影 + 安全区；左侧图标按钮 88rpx；右侧两个胶囊按钮各占一半、间距 16 |
| 浮动按钮 | 88rpx 圆形；白底 + 阴影；购物车浮标用黑底白图标 |
| 空状态 | 图标 160rpx + 文案 28rpx 次文字 + 可选按钮 |
| 骨架屏 | 底色 #efeff2 + shimmer；圆角与卡片一致 |
| 底部弹层 | 顶部圆角 24；遮罩 rgba(0,0,0,0.4) |
| 表单 | 标签顶部左对齐 26rpx 次文字；输入区高 88rpx；错误提示 22rpx 危险色，仅提交时出现 |

## 5. 硬约束检查清单

| # | 检查项 |
|---|---|
| 1 | 没有裸 Id、枚举数字、JSON 原文、时间戳、null |
| 2 | 金额走统一格式化：带 `¥`、整数省略小数、非整数两位 |
| 3 | 颜色只引用 token；价格红 / 自营蓝 / 青色不被平台主题覆盖 |
| 4 | 间距只用 8 / 16 / 24 / 32 / 40 / 48 / 64 |
| 5 | 渐变只允许会员卡、主 CTA、会员等级标签三处 |
| 6 | 可点元素热区 ≥ 88rpx；吸底栏含安全区 |
| 7 | 危险操作二次确认，主按钮危险色 |
| 8 | 列表有空状态与骨架屏；加载失败有重试 |
| 9 | tabBar 由装修配置驱动，缺配置时用内置兜底 |
| 10 | 所有页面适配 375 / 390 / 414 宽度与底部安全区 |
