# 小程序重建需求（逐页确认）

> 用途：记录小程序重写的全局决策与逐页需求。每确认一页在本文件追加一节，
> 后端改动与前端实现都以本文件为准；需求确认完成后与代码同批更新业务文档。

## 0. 全局决策

| 项 | 结论 |
|---|---|
| 交付形态 | uni-app（Vue3 + TypeScript），同时构建微信小程序与 H5 |
| 账号模型 | 每个平台各自一套客户账号（平台内账号），同一手机号可在不同平台各注册一个 |
| 存量数据 | 现有客户数据统一回填 `DEMOPL`；本地演示平台使用 `QHRQDB` |
| 平台切换 | 入口在首页 / 我的页顶部左上角；切换后清空本地业务缓存、回到首页 |
| 切换后登录态 | 本地按平台分别保存登录态；目标平台无登录态时按游客处理（可浏览、不可交易） |
| 登录方式 | 复用现有账号密码，不做微信登录 |
| 支付 | 仅模拟支付 |
| 装修 | 首页 / 我的页（平台装修）+ 店铺页（商户装修）由后台已发布配置驱动 |
| tabBar | 由装修配置驱动，使用自定义 tabBar（微信端 `custom-tab-bar`，H5 等价实现）；缺配置时用内置兜底 |
| 视觉 | 见 [`miniprogram-visual-spec.md`](miniprogram-visual-spec.md)（基于参考图 + 现有苹果风 token，已确认） |
| 明确不做 | 定位、平台评分、微信登录、微信支付、分类页品牌入口 |
| 小程序 AppId | 暂无真实 AppId，用模拟 AppId 本地调试 |
| 短信通道 | 服务商未定；接口配置化，本地用固定验证码 + 日志输出 |
| 平台停用 | 停用平台的客户账号禁止登录 |
| 文档同步 | 本次 45 项后端 / 后台改动与 `BUSINESS.md`、`DATA_SPEC.md`、`FRONTEND_DESIGN.md`、`TEST_CASES.md`、`REVIEW.md` 在第一批代码改动时同批更新 |

## 2. 逐页需求

### P01 首页（已确认）

**顶部栏**

1. 左上角：平台 Logo + 商城名 + 下拉箭头，点击进入平台切换；不放定位。
2. 中间：搜索框（圆角胶囊，放大镜 + 装修组件配置的占位文案）。
3. 右侧：不放任何功能图标（不做评分、分享、客服入口）。
4. 公告：多条公告轮播，后台单独维护多条公告，每条可配跳转。

**装修楼层**

1. 严格按平台装修「首页」已发布配置的 `components` 顺序、`span`、`height` 渲染。
2. 首页可用组件：轮播图、金刚区宫格、分类导航、商品双列/三列网格、商品横向滑动、
   优惠券专区、活动专区、秒杀专区、店铺列表、图文广告、公告栏、标题栏、分割线、
   留白、搜索框、购物车浮标、会员问候卡、权益行。
3. 会员问候卡与权益行允许配置在首页（需修改组件注册表的页面归属）。
4. 单个组件数据为空则整块不渲染；单个组件请求失败只影响该组件，不整页报错。
5. 商品网格支持 2 列 / 3 列；平台自营（`merchantId = 0`）显示「自营」标签。

**底部 tabBar**

由装修配置驱动；无配置时使用内置兜底（首页 / 分类 / 购物车 / 我的）。

**装修组件属性扩展**

| 组件 | 新增可配置属性 |
|---|---|
| 轮播图 | 每张图独立配图片、跳转类型与参数、排序；最多 8 张 |
| 金刚区宫格 | 每格独立配图标、文案、跳转；建议 4 个/行 |
| 分类导航 | 选择分类、展示数量、是否含下级 |
| 商品网格 | 列数（2/3）、商品范围（全部/分类/品牌/商品）、排序、数量、是否显示「查看更多」 |
| 商品横向滑动 | 商品范围、排序、数量、是否显示自营标签 |
| 优惠券专区 | 选择券活动、数量 |
| 活动专区 | 选择活动、数量、卡片样式（图片 + 标题 + 活动时间） |
| 秒杀专区 | 选择场次、数量 |
| 店铺列表 | 数量、排序 |
| 公告栏 | 选择公告或按顺序轮播全部 |
| 图文广告 | 图片、标题、描述、跳转 |

**对接接口**

`design/PlatformStore`、公开平台信息、公告列表、`shop/products/List`、
`marketing/activities/FinalPriceBatch`、`shop/catalog/CategoryTree`、`coupons/Available`、
公开活动列表、`marketing/seckill/sessions/Public`、`merchants/Shop`。

### P02 分类（已确认）

**功能顺序**

1. 顶部：标题「分类」+ 搜索入口（进入 P05）。
2. 左侧：一级分类竖排列表，可滚动，选中项用平台主题色高亮。
3. 右侧：跟随选中一级分类变化。
   1. 二级分类图标网格（图标 + 名称）。
   2. 三级分类文字 chips。
   3. 该分类下的商品瀑布流（2 列，含到手价、划线原价、优惠标签）。
4. 空状态：该分类无商品时显示提示 + 「看看全部商品」按钮。
5. 底部：装修驱动的 tabBar。

**明确不做**

不做分类大图 banner，不做品牌入口。

**平台过滤口径**

分类与品牌的「公共数据」用 `platform_id = 0` 表达，C 端按平台过滤时条件为
`platform_id = 当前平台 OR platform_id = 0`。

**对接接口**

`shop/catalog/CategoryTree`、`shop/products/List`、`marketing/activities/FinalPriceBatch`。

### P03 购物车（已确认）

**功能顺序**

1. 顶部：标题「购物车」+ 右侧「编辑 / 完成」切换。
2. 商品区：按店铺分组，每组显示店铺名（可点进店铺页）+ 该店商品行。
3. 商品行：勾选框、主图、商品名、规格、当前售价、数量步进器、删除。
4. 显示当前售价 + 到手价标签。
5. 失效商品：单独分组置灰，提供一键清空。
6. 底部吸底栏：全选、合计金额、去结算（含已选件数）。
7. 空状态：「购物车还是空的」+ 去逛逛。
8. 底部：装修驱动的 tabBar。

**已确认规则**

- 跨店铺勾选策略：只能选中同一店铺，切店自动取消其它勾选；一店一次结算。
- 全选只作用于当前店铺。
- 删除交互：左滑删除。
- 不显示库存，结算时由后端校验。
- 店铺名可点击进入店铺页。

**对接接口**

`carts/List`、`carts/SetQuantity`、`carts/SetChecked`、`carts/Remove`、`carts/Clear`；
加购使用 `carts/Add`（增量语义）。

### P04 我的（已确认）

**功能顺序**

1. 顶部用户区（固定模板，不参与装修）：左上角平台切换；
   未登录显示头像占位 + 「登录 / 注册」；已登录显示头像、昵称、脱敏手机号、会员等级、编辑资料入口。
2. 会员区：会员问候卡 + 权益行（装修组件，默认模板预置）；等级只显示「普通会员」。
3. 会员问候卡三项数据：优惠券 / 积分 / 收藏。
4. 服务宫格（装修组件，5 列 × 1 行）：我的订单、券包、积分、收藏、地址。
5. 其余装修楼层。
6. 设置行：我的评价、领券中心、个人资料、用户协议、隐私政策、关于我们、退出登录。
7. 底部：装修驱动的 tabBar。

**已确认规则**

- 订单只保留一个「我的订单」图标，点击进入订单列表页；不做状态快捷入口与角标统计。
- 未登录时不请求个人数据，会员卡与权益行不展示个人数据。
- 用户协议 / 隐私政策 / 关于我们为独立页面（P32 / P33 / P34），内容来自后台平台配置。

**对接接口**

`customers/Profile`、`points/Balance`、`coupons/My`、`customers/favorites/List`（取 Total 作为收藏数）、
`customers/Logout`。

### P05 搜索（已确认）

**功能顺序**

1. 顶部：搜索输入框（自动聚焦）+ 右侧「取消」。
2. 搜索历史：本地保存，按平台分键，最近 10 条，可单删 / 清空。
3. 热门搜索：标签形式，后台按平台维护（词 + 排序 + 启停），C 端公开接口下发。
4. 输入联想：输入防抖 300ms 请求建议词，点击直接搜索。
5. 点击搜索 / 热搜词 / 联想词进入 P06 商品列表（带 `keyword`）。
6. 无结果：空状态 + 推荐商品兜底。

**价格排序口径（方案 A）**

价格排序与价格区间按「SKU 最低售价」走数据库查询路径，保证全局排序正确；
选择价格排序或价格区间时关键词使用 `LIKE`，匹配精度低于 IK。
排序依据是售价，不是活动后到手价（到手价无法全局排序）。

**联想实现口径**

不引入 ES completion suggester，避免 mapping 变更与全量重建索引；
联想词 = 热搜词匹配 + 商品名前缀，最多 10 条。

**对接接口**

`shop/products/Search`、`shop/products/List`；新增热搜词公开接口与联想接口。

### P06 商品列表（已确认）

**共用来源**

搜索结果、分类点击、品牌点击、全部商品入口；店铺页 P13 内嵌同一套商品卡与筛选。

**功能顺序**

1. 顶部：返回 + 标题（关键词 / 分类名 / 品牌名 / 全部商品）+ 搜索入口。
2. 排序栏：综合、销量、价格（可切换升降序）、上新；右侧筛选入口。
3. 筛选抽屉：分类（三级、多选）、品牌（多选）、价格区间；底部重置 + 确定。
4. 商品区：支持 2 列瀑布流与单列列表切换。
5. 分页：下拉刷新 + 懒加载下一页（每页 20），首屏骨架屏，到底提示。
6. 显示「共 N 件商品」。
7. 空状态：提示 + 重置筛选 + 推荐商品。

**商品卡字段**

主图、名称（最多 2 行）、到手价、划线原价、自营标签、销量、评价分。
不显示优惠来源标签与评价数。

**排序口径**

| 排序 | 实现路径 |
|---|---|
| 综合 | 有关键词走 ES 相关度；无关键词走数据库默认（运营排序值 + 销量） |
| 销量 | ES 或数据库 |
| 价格 | 数据库，按 SKU 最低售价全局排序 |
| 上新 | 数据库，按创建时间（ES 索引无 createdAt） |
| 价格区间 | 数据库过滤 |

筛选抽屉的分类与品牌为**多选**，后端需支持 `categoryIds` / `brandIds`。
价格区间同时提供预设档位多选（0-50 / 50-100 / 100-200 / 200 以上）与手输最小 / 最大值。

### P07 商品详情（已确认）

**功能顺序**

1. 顶部：返回 + 微信原生转发 + 收藏入口。
2. 图集轮播：直接使用后台商品表单维护的商品轮播图，点击可预览大图；轮播为空时回落主图。
3. 价格区：到手价大字 + 划线原价 + 优惠来源标签 + 销量 + 评价分。
4. 标题区：商品名、副标题、品牌、分类。
5. 配送与服务：配送方式说明 + 服务保障，两项均取**商户级别**配置。
6. 规格区：显示已选规格，点击弹出 SKU 选择弹层。
7. 评价区：均分 + 评价数 + 前 2 条 + 「查看全部(N)」进入 P08。
8. 详情图：长图平铺、懒加载。
9. 吸底栏：收藏、加入购物车、立即购买（不做客服入口）。
10. SKU 选择弹层：SKU 图、价格、规格值选择、数量步进器、确认按钮。

**已确认规则**

- 不存在的规格组合置灰不可选。
- 购买数量上限 99。
- 未登录点加购 / 立即购买跳登录页，登录后返回本页继续。
- 分享只用微信原生转发，不额外做分享按钮。

### P08 评价列表（已确认）

**功能顺序**

1. 顶部：返回 + 标题「商品评价」。
2. 评分摘要：均分大字、星级、评价数。
3. 筛选条：全部 / 有图 / 好评 / 中评 / 差评。
4. 评价列表，每条包含：头像与昵称、昵称后空一段再显示本单 SKU 规格名、星级、时间、
   内容、图片九宫格（点击大图预览）、商户 / 平台回复、追评（挂在首评下方）。
5. 分页：每页 10 条，下拉刷新 + 懒加载，不做点击分页。
6. 空状态：「暂无评价」。

**已确认规则**

- 只做 SPU 级评价，不做 SKU 级评价筛选。
- 排序仅最新优先，不做排序切换。
- 回复只显示「商家回复 / 平台回复」+ 内容 + 时间，不显示回复人姓名。
- 追评挂在首评下方，不单独参与评分。

### P09 商城页（已确认）

**功能顺序**

1. 顶部：标题「商城」+ 搜索入口。
2. Tab 栏：秒杀 / 推荐 / 活动，按后台开关与顺序显示，文案后台可改。
3. 秒杀 Tab：场次卡片 + 倒计时 + 秒杀商品；点击场次卡片进 P10，点击商品进 P07。
4. 推荐 Tab：商品瀑布流，复用 P06 商品卡与懒加载，带排序栏（综合 / 销量 / 价格 / 上新），不做筛选抽屉。
5. 活动 Tab：活动卡片列表（图片 + 标题 + 活动时间），点击进入活动商品列表页。
6. 某 Tab 无数据时保留 Tab 并显示空状态。

**入口**

装修 tabBar 可把商城页配成 tab；装修组件的跳转新增 `mall` 目标。

### P10 秒杀频道（已确认）

**功能顺序**

1. 顶部：返回 + 标题「限时抢购」（配进 tabBar 时无返回）。
2. 场次区：进行中在前、即将开始在后分组；显示场次名、状态标签、倒计时。
3. 商品区：图片、名称、规格、划线原价、秒杀价大字、剩余数量、每人限购。
4. 抢购确认层：一键抢购；默认选中最优券、默认不用积分、实物商品默认选中默认地址；
   提供「使用优惠」展开区可改券与填积分。
5. 提交后按 `requestId` 轮询结果；成功进支付页 P15，失败按结果码提示。
6. 曝光埋点：进入频道并渲染出场次后按场次调 `View` 记录 PV。
7. 倒计时归零自动刷新；支持下拉刷新；空状态「暂无秒杀场次」。

**已确认规则**

- 实物商品必选收货地址，虚拟商品不需要。
- 数量固定 1 件。
- 售罄商品不下发、不展示。

### P11 活动专区（已确认）

**定位**

P11 为「活动商品列表页」（带 `activityId`）；活动总览由商城页活动 Tab 与首页活动专区组件承担。

**功能顺序**

1. 顶部：返回 + 活动名。
2. 活动头部：活动主图、活动时间（完整格式 `yyyy-MM-dd HH:mm:ss - yyyy-MM-dd HH:mm:ss`）、活动说明 / 规则。
3. 商品区：复用 P06 商品卡与懒加载，展示活动后的到手价。
4. 排序栏：综合 / 销量 / 价格 / 上新。
5. 空状态：该活动暂无商品。

**已确认规则**

- 活动表新增活动主图与活动说明 / 规则字段，后台活动表单可维护。
- 活动目标按 SKU 指定时，列表按所属 SPU 聚合去重展示。
