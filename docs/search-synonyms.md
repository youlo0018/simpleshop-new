# 商品搜索同义词

## 目标

同义词只负责提高召回率，不替代商品状态、价格、销量等权威数据。商品最终仍以 PostgreSQL
中的审核状态、上下架状态和价格为准。

## 查询链路

1. 前台传入关键词、平台 Id、分类和品牌上下文。
2. ProductService 从 `search_synonym` 读取启用规则。
3. 按全局、平台、分类、品牌作用域筛选适用规则。
4. 在查询层展开关键词，最多生成 24 个查询变体。
5. Elasticsearch 对变体分别执行 `multi_match`，按权重参与相关度打分。
6. ES 只返回商品 Id，商品详情和价格回 PostgreSQL 获取。

同义词不写入 ES 分析器，因此新增、编辑、启停和删除规则都无需重建索引。

## 规则类型

| 类型 | 语义 | 默认权重 |
|---|---|---:|
| 等价词 | 组内词条双向互通 | 0.90 |
| 单向映射 | 第一个词是来源，其余词是目标 | 0.82 |
| 错别字纠正 | 第一项为用户常见错误，其余为正确词 | 1.00 |
| 类目扩展 | 低权重类目召回，不能压过原词 | 0.35 |

## 作用域

- 全局：所有平台适用。
- 平台：只在指定 `platformId` 生效。
- 分类：只在搜索请求命中指定分类时生效。
- 品牌：只在搜索请求命中指定品牌时生效。

多个规则可以叠加，但每次请求最多生成 24 个关键词变体，防止同义词组合爆炸。

## 后台能力

- 按词条、备注、类型、作用域、状态筛选。
- 新增、编辑、启停和删除规则。
- 关键词扩展预览，显示实际查询词、权重、规则来源和命中词。
- 同作用域、同类型、同词条的重复规则直接拒绝。

后台入口：商品与库存 → 搜索索引 → 商品搜索同义词。
